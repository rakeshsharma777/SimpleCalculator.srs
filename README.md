# SimpleCalculator.srs

Simple Python Calculator Description

This Python program is a command-line calculator that performs basic arithmetic operations:  
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

Features:
1. **User-Friendly Menu** – Displays available operations.  
2. **Input Validation** – Checks if the user enters valid numbers.  
3. **Error Handling** – Prevents division by zero.  
4. **Multiple Calculations** – Allows repeated use until the user exits.  

**How It Works:**  
1. The user selects an operation (1-4).  
2. The program prompts for two numbers.  
3. It performs the calculation and displays the result.  
4. The user can choose to continue or exit.
